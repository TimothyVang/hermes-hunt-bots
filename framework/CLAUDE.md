# Claude Project Guide

Follow `AGENTS.md` in this directory and higher-priority instructions. This folder is a standalone, portable human-operated bot framework intended to be developed with Hermes or other coding agents. Start with `README.md` and `hermes-setup.md`.

Keep Python runtime dependencies minimal, preserve cross-platform behavior, and distinguish actual bot execution from role templates or plans. Do not expose credentials, send private or controlled data to an external provider, enable unattended actions, or trade without the authorization described in `AGENTS.md`.
